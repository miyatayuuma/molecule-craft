# H Veil — 水素の帳 / v35

v1を含むmain `df98647051bc1849291956c9577ed161388d30d1` を起点にリファイン。H Veilだけを対象とし、新元素・新ステージ・敵・クラフトツリーは追加しない。既存Three.js制作、162分子の認識、図鑑、電子ドラッグ、軸回転は維持する。

## v1の評価と変更理由

公開中のv1で採集画面の起動、パッドでの通常飛行、回収、帰還・再出発、分岐と反発場の表示を確認した。粒子と背景の区別、濃い列の誘引、帰還の短さは残す。検証ブラウザはWebGLが無効で、H₂初回クラフトの実画面操作・全条件の複数周回は実施できていない。長いドラッグ操作もタイムアウトした。以下の数値は本番シミュレーション関数による比較で、実機の主観評価ではない。

| 問題 | v35での対応 |
|---|---|
| 無入力で完全停止し、再入力が発進になる | 通常速度の約17%で漂う。入力時は加速・操舵を優先し、小入力で位置を調整できる |
| ブースト中ほど切り返しが遅く、大きく行き過ぎる | ブーストの旋回・速度追従を強化。急転回中は少し減速し、短い横滑りを残す |
| 円形の反発場が押し戻し・待ちを生む | 常時横へ流れる粒子流。強弱は連続変化し、通常飛行でも逆らって横断できる。逆向きの力に上限を設ける |
| 障害が破線の円に見える | 流れる微粒子、柔らかい雲、曲がった細い筋で流向を見せる。境界線は描かない |
| ブーストは得になるが、吸引範囲の差が小さい | 最大128の吸引半径で、高密度列の両肩までまとめて回収。通常は肩へ寄る判断が必要 |
| 周回の終点で結果画面が飛行を中断する | 短い周回通知だけにし、操舵・CHAINを保ったまま次の列へ。帰還時に結果を表示 |
| 連続音が短く、粒子の尾が実際の軌道と一致しない | 柔らかい音階・倍音・吸引の空気音。吸引粒子は加速する曲線と実軌道の短い尾を持つ |

同じ180度の入力を与えた計測では、通常の切り返しが約0.83秒→0.50秒、ブーストが約1.07秒→0.38秒。ブースト時の切り返し終了時の開始地点からの距離は約406→112。カメラには前方の先読みと穏やかなズームを付け、操作不能時間は設けない。

## 遊ぶ流れ

1. クラフト上部の「Hを採集」から出発。左パッド／矢印／WASDで操舵。離すとゆっくり漂う。
2. 緩い初心者ラインから安全路／高密度路を選ぶ。主経路・分岐・合流・空白・技術ラインは固定。
3. 初回はH24でクラフトへの案内。案内から戻れば同じページ内で探索位置を保持する。
4. H原子を2つ置き、既存の電子ドラッグでH₂を完成。「H₂を燃料に保管」で2原子を燃料1個へ変える。
5. 解放後の「H₂ 生成 · 長押し」は触れた瞬間に1個、360ms後から140ms間隔で1個ずつ生成。H × 2を消費してH₂1個。指離し・キャンセル・フォーカス離脱・非表示・原子不足で停止。タップとキーボードも使用可能。
6. 採集中は右のH₂ボタン／Spaceで1個消費。空白の接続、幅広い密度帯の一括吸引、粒子流の横断、外縁へ利用する。
7. ブーストで外縁を越えると未知の粒子雲が一瞬見え、初回到達を保存。その先のステージは実装しない。
8. スタートへ戻れば飛行を止めず次の周回へ。右上からいつでも帰還でき、取得したHは失わない。

H以外の既存原子は今回採集先を追加しないため、従来の解放条件と自由配置を維持。旧図鑑で発見済みのH₂はレシピを引き継ぐが、無料燃料は配らない。

高密度帯の追加場所・粒子流の位置と位相・特殊粒子は出発ごとに小さく変わる。主要ラインのランダム散布はしない。連続周回中は同じマップを保ち、帰還して出発し直すと種を変える。

Canvas 2D。遠景の柔らかい雲と発光スプライトはキャッシュし、DPR最大1.75、吸引エフェクト最大160。回収判定は飛行区間全体を使い、低fpsで粒子をすり抜けない。15/30/60fpsで経路・回収数・CHAINが一致する。縮小モーション設定ではズーム・航跡の強調・振動を抑える。音は意味別イベントで差し替え可能。

## 資源・保存・初期化

Hは原子／部品を配置すると消費し、削除・全消去・整理で返却。整理を取り消すと再消費する。H₂保管は完成グラフから2原子を取り出すため、再認識や連打では燃料が増えない。

`molecule-craft.resources.v1` に元素、分子、レシピ、進行、制作スナップショットをまとめ、資源と制作を同じ書き込みで確定する。旧制作保存は初回移行後も控えとして残す。図鑑キーは従来のまま。破損・未来形式・別タブ更新は上書きを止め、容量不足は警告する。通常の更新で既存進行を消去しない。

採集中は約1秒ごと、および帰還・非表示・終了時に保存する。OS強制終了では最後の保存から最大約1秒は保証できない。通常の再読み込みはクラフトから再開する。

メニューの「ゲーム進行を最初からやり直す」は確認後に全進行を消去。「開発用 · 初期化テスト」は折りたたみ内で図鑑、レシピ、元素、分子、探索進行、最大CHAIN、制作フィールドを選択できる。

- 図鑑／レシピの初期化では、古い完成分子から即再発見しないようフィールドも空にし、配置済みの原子をストックへ返す。
- 元素の初期化でもフィールドを空にするが、原子は返さない。分子ストックやレシピは選ばなければ維持する。
- 図鑑の初期化は部品・元素解放・発見記録も空にする。探索進行はクリア、出発回数、初回案内、特殊粒子記録。音設定は保持する。
- 正本に初期化の意図を先に記録し、図鑑・旧制作・ヘルプの初期化を再実行可能な形で適用する。途中終了や容量不足後も、起動時に残りを完了する。
- 確定後の古い制作画面の保存を停止。図鑑も初期化世代を確認し、別タブから発見が復活するのを防ぐ。他アプリの保存やブラウザ全体の保存は触らない。
