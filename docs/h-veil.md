# H Veil — 水素の帳

最新main `404c3f5965d06d80b63077435456d97148583f32` から実装。対象は採集ステージ1つ。既存のThree.js制作、分子認識DB162件、図鑑、電子ドラッグ、軸回転を維持する。

## 遊ぶ流れ

1. クラフト上部の「Hを採集」から出発。左パッドを倒して飛ぶ。離すと減速する。PCは矢印/WASD。
2. 光の列に乗って塵を連続回収。一定時間内の回収でCHAINが継続。広い安全路と濃い反発場ルートを選ぶ。
3. 初回はHを24集めるとクラフトへの案内が現れる。案内から帰れば同じ探索を再開できる。
4. 通常のH原子ボタンで2個置き、既存のシアンの電子をドラッグしてH₂を完成させる。「H₂を燃料に保管」で完成品を取り出す。
5. 発見後はHがある限り、最大5個ずつ高速生成できる。H₂1個につきHを2消費。探索では右のH₂ボタン、またはSpaceで1個消費してブースト。
6. 空白を横断してCHAINをつなぐ、反発場を突破する、外縁の逆流を抜ける。外縁の先に異なる粒子雲が一瞬見え、初回到達を保存する。
7. スタートの流れへ戻れば周回結果。すぐ次の周回かクラフト帰還を選べる。途中でも右上から帰還可能。罰金・死亡・所持資源の没収なし。

一度H₂を発見済みの旧図鑑はレシピを引き継ぐ。無料燃料は配らない。H以外の原子は今回採集先を追加しないため、既存の解放条件・自由配置を維持する。

## 操作と表現の設計

Canvas 2Dの青白い粒子、抑えた粒子雲、細い流線で統一。背景と資源は輝度・サイズを分ける。画面前方を広く取る追従カメラ、曲線吸引、細い航跡を使用。ピクセル比は最大1.75、回収エフェクト最大120。

通常飛行は目標速度への指数補間と旋回上限を持つ。操舵が合う近傍の列だけ弱く補助し、自動操縦しない。反発場は1.2秒の予告後に広がり、ブースト中は押し出しを88%抑える。失敗は停止・戦闘・資源喪失ではなくラインを外すこと。

固定の主経路に対し、周回ごとに高密度の追加位置、反発場の位置・位相、高純度H塵の出現を変える。塵のランダム散布はしない。回収済みの列は62秒後に再生する。低確率の高純度H塵はH+8と発見フックだけで、別報酬ツリーを作らない。

Web Audioの音は通常移動、回収、CHAIN音階、高CHAINの倍音、ブースト、高密度帯、特殊粒子、CHAIN終了に分離。音イベントの境界で差し替え可能。ミュートを保存し、非表示・中断中は停止。振動は対応端末だけで短く、動きを減らす設定では省く。

## 資源と保存

Hは原子配置時に消費し、部品も含まれるHを消費する。削除・全消去・自動整理はHを返却し、整理の取り消しは再消費する。H₂の保管は実際の完成グラフから2原子を取り出して在庫1に変える。再認識やボタン連打だけでは増えない。ほかの分子もHを配置した時点で素材を使っており、分解すれば戻る。

`molecule-craft.resources.v1` の1つのJSONに元素在庫、分子在庫、レシピ、進行、既存形式の制作スナップショットを格納する。資源と制作の書き込みを分けると中断時に二重消費・二重返却が生じるため、同一書き込みで確定する。既存の `workspace-save.js` の検証・座標復元を保存アダプターから再利用する。

初回に旧制作保存から移行し、その時点の原子は既存作品として引き継ぐ。旧保存キーは移行前の控えとして残す。以後は新しい統合保存が正本。図鑑キーは変更しない。破損・未来形式・別タブ更新は上書きを停止して表示する。容量不足は警告し、メモリ内の状態を保持する。

探索中は約1秒ごと、および帰還・タブ非表示・ページ終了時に保存。突然のOS強制終了では最後の保存以降の最大約1秒は保証できない。資源・H₂・レシピ・初回到達・最高CHAIN・周回数・特殊粒子・音設定を保存。通常の再読み込みはクラフトから再開する。初回案内からの一時帰還では同じページ内に限り探索位置を維持する。

配信資産は既存のハッシュ付きオフラインキャッシュに含める。外部CDN・ゲーム実行時のnpm依存を追加しない。
