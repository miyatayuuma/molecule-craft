## Reading the matrix

- `U`: emitted evidence unit count = consumed source molecule instances; **not necessarily chemical repeat units**. Five routes have U=3; twenty have U=4. Sequence in the motif column is the actual `representativeSequence`.
- `A/B/μ`: emitted main-graph atom count / bond count / cycle rank B−A+1. Explicit H included; main graph connected. μ counts independent graph cycles, not a separately inferred material morphology.
- `O`: actual distinct bond orders. Multiple orders remain in the chemical graph regardless of renderer lane limitations.
- `P`: number of actual `representation.continuations` valence-deficit ports. It is not the route's generic `continuationMarkers` category.
- `X`: actual bonds between different source-instance origins. For PF, transferred H makes X=4 although evidence `interUnitLinks`=3. Every other row has `interUnitLinks`=U−1=X; every route has `interUnitLinks`=U−1. No junction may be inferred from PF's raw origin grouping.
- `W`: actual completed water byproducts, separately partitioned from the main graph. Ring-opening evidence is 4 only for PEO and 0 for the other routes. PF requires `methylene-bridge` and `hydroxymethyl-site`; other `requiredFeatures` lists are empty.
- Bond/origin authority for **every row**: canonical S1→S2→S3 (`data/molecules.json` filtered Feed source → route-specific Core edits/partition → `sample.fragment`), keyed by `(instanceId, sourceAtomIndex)`. Evidence column pins the route line; graph metrics are reproduced by canonical Appendix A.
- Existing presentation for **every row**: canonical S5 XYZ → S4 finite Three.js; S6 finite fallback if diagnostics reject. All 25 passed the existing local geometry test with zero fallback. This is compatibility with present assertions, not final scientific/visual acceptance. All sample identities follow S2 `makeSample()` and all completion/discovery events follow S4/S7.

Qualifiers are copied from actual route data: S=`STEREOCHEMISTRY NOT SPECIFIED`; L=`REPRESENTATIVE LOCAL SEGMENT`; B=`BULK COMPOSITION NOT IMPLIED`; M=`MICROSTRUCTURE VARIES`; R=`REGIOCHEMISTRY VARIES`; N=`NETWORK CONTINUES`. A missing qualifier does not independently authorize stereochemistry. Educational column supplies Task② classification inputs, not final teaching copy.
