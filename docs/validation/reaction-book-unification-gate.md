# MC-RB-03 反応図鑑ビジュアル統一ゲート

## 対象
反応図鑑14分類・54経路。既存の発見状態、反応authority、LAB導線、保存形式は不変。

## 必須ゲート
1. 全54経路の一覧サムネイルに同一の模型コンポーネントを使用する。先行5経路の独立模式図も禁止。
2. 個別サムネイルの模型には独立した背景枠、背景タイル、装飾境界を設けない。
3. 高分子25経路の生成物には、高分子図鑑が現に使用する「構成単位」模型の同一アセット／描画経路を使用する。反応図鑑専用の高分子画像は禁止。
4. 14分類のSVGアニメーション内に text、foreignObject、文字の描画を含めない。元素名、反応名、H₂O、R、R′、X、Yも禁止。分子は円・線と色・大きさ・配置で示す。
5. 分類アニメーションは5〜6秒を基準にする。画面外停止、reduced-motion、フェードでのリセットを維持する。
6. 未発見の反応名・構造をDOMに出さない。hinted／verifiedの詳細とLAB導線を維持する。
7. Chromium 360px・1280pxで分類→反応→詳細→LABを限定受入。既存LAB・高分子3Dの全件再試験は不要。
8. PWA precacheを再生成し --check PASS、GitHub Pages公開後に実配信を確認する。

## 判定
上記を満たし、限定テストPASSならマージ・公開可。視覚的な微修正は公開後の実機フィードバックで対応する。
