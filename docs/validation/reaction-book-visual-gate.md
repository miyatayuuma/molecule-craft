## 視覚受入（自動PASSと別）

- V01: 同じ図鑑UIで14分類の形と動きが判別できる。色だけで区別させない。
- V02: 54経路の前後模型と条件が相互に区別でき、化学的誤表現がない。機構や中間体を断定しない。
- V03: スマホ360px・PCの実画面を提示し、文字・模型・操作が読み取れる。

## 試作と禁止範囲

- グループ: 全14分類。過去の4種の手描き模式図を維持し、残り10分類を追加。
- 個別: 全54経路。5件の手描き模式図は参考として残し、一覧と詳細では既存の正本由来の分子／高分子模型を表示。
- まず品質ゲートを先行コミットし、同一Draft PRに後続Work実装を積む。
- 2026-10-29のユーザー方針により、先に14分類/54反応へ実装を展開し、視覚上の細部は完成版を見てから修正する。視覚上の細部を自動ゲートの停止条件にしない。
- mainマージと本番デプロイはユーザーの公開判断まで行わない。
- 既知の無関係テスト失敗は差分由来のものと区別する。
