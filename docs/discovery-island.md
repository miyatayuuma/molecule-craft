# Discovery Island — 最初の島

## 狙いと範囲

分子を作る → 島に持っていく → 場所を選んで落とす → 周囲も変わる、という短い循環を作る。課題一覧、正解の分子名、HPゲージは出さない。島は1つ、作用する素材は10種。原子の結合ルール、既存162分子の認識、部品の解放条件は変えていない。

一度完成させた分子は**標本ボトル**として繰り返し使える。水を何度も作り直す作業を避け、投入場所・量・順番の実験に時間を使う。初期配布の完成分子や、図鑑を埋めるための自動組立はない。旧図鑑の発見は標本へ引き継ぐ。

## 島の配置

机上の陶器の台に、池の穴がある丸い島を載せたジオラマ。草木、金属板、コンロ、レンズ、アーチ状の洞窟、指示薬の結晶、風船フラスコは3D形状。ブロック地形や細密テクスチャは使わない。

| 場所 | 最初に見える状況 | 状態が変わると見えるもの |
|---|---|---|
| 池 | 砂の底、わずかな水、岸で休む生物 | 水面拡大、湿った土、泳ぐ生物、あふれる滝と虹 |
| 庭 | 曲がった茎、下向きの葉 | 立ち上がる茎、葉色、成長、開花、草を好む生物 |
| 金属の装置 | 銅色/銀色の板と空の容器 | 水位、塩の溶解、線を走る光、電球、析出した結晶 |
| コンロ | 火花スイッチ、燃料の窓、風車 | 炎の大きさ・色、蒸気、風車、加熱・焦げ跡 |
| 洞窟 | 暗い奥、閉じた柵、消えたランプ | 光る結晶、上がる柵、現れる道、貝の行進 |
| レンズ | ほこりと樹脂のよごれ | 水でほこりだけ落ちる、有機溶媒で樹脂が取れる |
| 結晶の皿 | 紫の結晶 | 酸性/塩基性の色、中和した色、溶解の粒子 |
| 風船フラスコ | しぼんだ風船 | 軽い気体で膨らみ、持ち上がる。重い気体では下がる |
| 砂地 | 乾いた砂と溝 | 濡れた色、余った水が池へ流れる |
| 岩場 | 白い結晶 | タップで塩の標本を採取 |

池と庭は水路で、金属の装置と洞窟はレンズを経由する配線でつなぐ。コンロには熱の配管もある。因果関係のつながりが、文章だけでなく島にも残る。

## 素材の選定

**9種のクラフト分子 + 1種の採集結晶**。Naは既存の元素/共有結合モデルに含まれない。NaClを偽の共有結合分子として追加する代わりに、岩場で採れるイオン結晶として扱う。

| 素材 | 主なゲーム属性 | 比べられる作用 |
|---|---|---|
| 水 H₂O | 液体、湿潤、水溶解の媒体 | 池を満たす、土を湿らす、希釈、消火。樹脂は残る |
| 酸素 O₂ | 酸素を供給 | 生物の環境改善、燃焼の増強。単独では燃料にならない |
| 二酸化炭素 CO₂ | 酸素を遠ざける、炭素源、弱い酸性 | 消火、水と光がある植物の成長。濃い気体は生物が避ける |
| 水素 H₂ | 燃料、軽い気体 | コンロでは燃焼、風船では浮力 |
| メタン CH₄ | 気体燃料 | 燃料だけでは発火しない。酸素・点火・量で炎が変わる |
| アンモニア NH₃ | 塩基性、窒素源、毒性、弱い導電効果 | 薄い条件の栄養、過剰投入の害、指示薬、中和 |
| エタノール C₂H₅OH | 液体燃料、有機溶媒、毒性 | レンズを洗う、コンロで燃える、水辺への過剰投入は害 |
| アセトン C₃H₆O | 強めの有機溶媒、液体燃料、毒性 | 樹脂をよく落とす。同じ場所で水/エタノールと比較できる |
| 酢酸 CH₃COOH | 酸性、弱い導電効果 | 結晶の色、中和、塩以外の電解液 |
| 塩 NaCl | 固体結晶、溶解による導電効果 | 水では溶解、装置では通電、池では塩分、炎では発色 |

数値は物性の実測値や現実の配合ではなく、無次元のゲーム値。「少し」は1単位、「たっぷり」は3単位。指示薬の結晶と熱電の配管は玩具世界の装置として簡略化している。塩水そのものが発電する、塩水の電解で無害な何かが発生する、といった表示はしない。

## 反応と連鎖

`REACTION_RULES` は素材の属性、対象のタグ、対象の現在状態を受け取る。湿潤、固体結晶、酸素環境、燃料、溶媒、酸/塩基、生物栄養、局所毒性、浮力、気体放出のルールを合成する。素材IDごとの巨大なswitchはない。

| 投入直後 | 続いて更新する世界 | 発見記録 |
|---|---|---|
| 水面が広がる | 土が湿る → 植物が起きる → 生物が池/庭へ移動 | 水・植物・生物を別々に記録 |
| 塩が落ちる | 水があれば溶解 → 電解液の導電性 → 金属の装置 → 配線の光 | 溶解と通電 |
| レンズが透ける | 装置の光または熱電の光が洞窟へ → 柵が上がる → 貝が現れる | 溶媒・洞窟・新しい生物 |
| 火花を出す | 燃料と酸素があれば燃える → 風車 → 配管の加熱 → 水が蒸発 → 塩が残る | 燃焼・増強・結晶 |
| 濃い環境になる | 生物が避難、植物がしおれる | 失敗も現象として登録 |
| 水を入れ替える | 濃度が下がる、空気が戻る → 生物が戻る | 復旧 |

投下は約0.56秒の3D落下の**着地時**に確定する。現象の記録は世界内で起きてから1.25秒後。成長は植物が育ってから、中和は色が中間へ戻ってから、析出は加熱によって溶けていた塩が戻ってから記録する。図鑑は作った分子、発見した現象、出会った生物を分ける。未発見の現象名や答えは先に出さない。

生物は3種・計6体。ミズポンは水量・塩分・毒性・酸素、コケモチは庭の状態、ホタル貝は洞窟の光と水辺を見て行動を選ぶ。位置は時間で補間し、瞬間移動させない。逃げる/泳ぐ/草を食む/光る/休むを外観と動きで区別する。

### 隠し現象（開発者向け）

8件: あふれる滝と虹、強い炎で回る風車、水素で浮く風船、中和で戻る指示薬の色、塩による黄色の炎、庭の開花、加熱で戻る塩の結晶、ホタル貝の行進。いずれも量・環境・組合せから生じる。特別な入力列や分子IDを並べる判定はない。

## 操作と復旧

- ボトルをタップしてから場所をタップ、またはボトルを上へドラッグして投下。ボトル棚の横方向はスクロールを維持する。
- 背景ドラッグは回転、2本指はズームとパン。回転/ピンチの終わりを投下と誤判定しない。タッチ中断・島の外への投下は取り消す。
- 新規の島操作ボタンは44px以上のタッチ領域。ボトルを運ぶ途中で2本目の指が入った場合は投下を取り消す。
- カメラの自動追従や発見による強制移動はない。全景ボタンはプレイヤーが押した時だけ作用する。
- 池/容器の排水は水と溶質を同じ割合で取り除く。水の追加・あふれによる希釈も可能。
- コンロは消火後に水が抜け、再点火できる。ゲームオーバーはない。
- 「島だけやり直す」は確認画面を挟み、島の環境を初期化。発見・生物図鑑・標本・制作中の分子を残す。

## 保存・中断・描画負荷

保存キーは `molecule-craft.discovery-island.v1`。環境、発見待ち、解放状態、標本、生物の位置/行動、音と画面の設定を保存。未来形式・破損・別タブの更新は保護し、無言で上書きしない。保存できない時は警告を表示する。

クラフト中、図鑑/メニュー表示中、バックグラウンドでは島の時間を進めない。投下途中の画面切替・終了はその投下を一度だけ確定して保存。放置時間を一括加算して島を壊さない。

描画は約30fpsを目標に上限を設け、ピクセル比は最大1.5。粒子は固定160枠・1描画、投下は同時8件まで、海岸の石と草はInstancedMesh。剛体・流体物理は使わない。初期島の幾何情報は通常描画199回・約40,700三角形（影のパスを除く）。これはGPUの実測fpsではない。
