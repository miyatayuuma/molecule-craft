# MC-COMPARE-02｜沸点比較・沸騰観察（正式実装）

## 入口と登録範囲

分子図鑑 → くらべる → `沸点`。試作フラグは不要で、通常表示・ゲームパッド十字キーの軸切替から選べる。通常のモル質量・原子数・樹形図の比較は変更しない。

全142分子のうち、信頼できる常圧沸点の資料が確認できた **112分子** を `data/boiling-points.json` に登録。従来の107分子に加え、NIST Chemistry WebBook を再照合してシクロブタン・ジフルオロメタン・1-ブチン・2-ブチン・カテコールを追加した。基礎データは PubChem PUG-View の実測物性資料（HSDB、ICSC、DOE PAC、CAMEO等）と NIST を照合したもので、出典名・PubChem CID をDBに保持する。

さらに `data/boiling-exceptions.json` の **4分子** を、必ず性質を区別して同じ比較用の紐に追加。二酸化炭素（−78.5 °C）とアセチレン（−84.7 °C）は**昇華点**、2-ブテン（異性体による0.9〜3.7 °C）とメチルエチルエーテル（文献差による6.6〜10.1 °C）は**沸点の幅**として扱う。幅の中心値は紐の並べ替えにのみ使用し、実測の確定値としては表示しない。表示値の揺れは文献・異性体の**不確実性を示す記号的な演出**であり、一つの試料の測定温度が実際に不規則変動するという主張ではない。

熱分解の可能性があるもの・常圧での意味ある相変化データが不十分な**残る26分子**は引き続き比較から外し、調査を継続。分解温度・減圧沸点を常圧沸点に読み替えたり、未知の値を推定で補ったりしない。

従来の3分子試作の表示値 n-ブタン −0.5 °C、エタノール 78.4 °C、水 100.0 °C は NIST Chemistry WebBook SRD69 に基づき維持した。

## 観察の流れ

1. 珠を台座に合わせる。ひも・非固定珠の運動は従来どおりの PBD で計算する。
2. 既発見で沸点が登録されている試料のみ、沸点より 55 °C 低い温度から約 2.25 秒で加熱する。序盤は一気に上昇し、沸点付近ではゆっくり近づく ease-out 曲線を採用。これは教育用の視覚演出であり、実物の温度上昇速度を測定したモデルではない。
3. 加熱初期に珠が浅いガラス皿の液体試料に変わる。この変形は比較 UI の視覚的な比喩であり、測定済みの融点での相転移を意味しない。沸点に至るまで気泡は出ない。
4. 沸点に達したら約 3 秒数値が止まる。液体内の気泡が浮かび、表面にさざ波と飛沫が立ち、湯気状の気体へ移行して液面が下がる。蒸発後も空の皿だけを残す。沸点の停滞は液相と気相の共存を説明する演出であり、分子自体の沸騰ではない。
5. 同じ珠にとどまる限り蒸発済みのまま。ほかの珠にフォーカスを移したら、前の珠に小さな液滴が集まり 1.7 秒ほどで再凝集する。皿は以前の珠に追従しない。切替後の再選択は可能。

**昇華例外**は液体を作らず、珠の状態から直接気体の粒子が出て消える。気泡・液面・皿・液滴の再凝集はすべて無効。温度計には「昇華点 · 1気圧」と明示する。**範囲例外**は液体の既存演出を使うが、固定の沸点とみなさず、「異性体ごとに沸点が異なる」または「資料によって沸点が異なる」という注記と上下限を併記。到達後に表示が範囲内で揺れる。`prefers-reduced-motion` が有効な場合は、静的な上下限と説明を表示する。

台座の白い発光ラインとドットは、GLB の独立した emissive テクスチャを利用して**表示温度（℃）そのもの**に応じた色へ変化する。氷点下は青系、25 °C 前後は白系、65 °C 付近は黄、85 °C 付近は琥珀、100 °C 付近は橙色。−5 °C に沸点がある試料は沸騰中も青、100 °C の試料は橙色になり、沸点到達率が同じでも色は同じにならない。これは温度を読み取りやすくする教育用の色表現であり、100 °C で金属が赤熱するという物理現象を意味しない。金属の暗い外殻は無着色。加熱の進行率は色相ではなく明るさに反映し、気化完了時とフォーカス切替時には滑らかに消灯する。

視認性の補強: PBR 材質の emissive 色変更だけでは ACES トーンマッピングと元の白い発光に色が埋もれやすい。そのため、GLB の同じ emissive テクスチャ・UV を共有する *tonemapped=false* の加算描画層を重ね、元の白発光は加熱時に弱める。さらに台座中心の補助光も表示温度に応じて着色する。Canvas フォールバックは元画像と冷色・暖色加工した２種の複製画像を温度でクロスフェードし、低温と高温をはっきり区別する。

未発見の分子は例外を含めて未知の珠として紐に並び、名前・値・外観データ・例外区分は非公開。未発見には加熱演出を付けない。例外の印「↗」「≈」は発見済みの珠にのみ表示。既存の発見・セーブ・データ型は変更しない。

## 技術・帰属

- Three.js 既存 r180 の WebGL シーンに統合。
- Three.quarks **v0.16.0**、MIT License、© 2019 Forrest Sun。`vendor/quarks/LICENSE` に原文を保持。`three.quarks.esm.js` を esbuild で一度だけバンドル、Three.js は `external` として import map で共用。エフェクト使用時のみ遅延読み込みする。
- WebGL 非対応・パーティクル読み込み失敗時には数値表示と既存 Canvas rope にフォールバック。
- 透明な浅皿・着色可能な液体ボディ・波打つ自由表面・メニスカスを Three.js で構築。液中の泡は 40 個以下の InstancedMesh、表面飛沫と気化の霧は低負荷の Quarks スプライト粒子。3D 流体ソルバーや物理的な気液界面計算ではない。
- 液体色は分子 DB の `phaseAppearance.liquid` を参照。記録のない物質と無色液体は淡い透明色にし、原子模型の元素カラーを流用しない。未知分子の色は非公開。
