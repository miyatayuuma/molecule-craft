# Molecule Craft

ブラウザ上で原子をつなぎ、分子の3D構造を組み立てる化学クラフトアプリです。

## 結合状態・特殊表示・操作復帰（v30）

- P/Sは通常の電子に加え、結合次数合計3→5 / 2→4→6へ進む薄紫の追加接続点を表示。これは操作用の輪であり、電子数や原子軌道そのものではない。H₂S/PCl₃など低い原子価での完成を維持する。
- COは他の原子に結合していないC=Oに限り、Oの電子対を共有して三重結合へ進む。完成後の形式電荷C−/O＋と各1組の非共有電子対をグラフから導出し、余分なCの接続点を消す。中性O一般の結合上限は変えない。保存形式・DBの整数結合次数は維持する。
- `geometryForAtom`を制作・図鑑で共有。多重結合も方向としては1つと数え、P/Sの二重結合に炭素のsp/sp²拘束を適用しない。SO₃の平面、PCl₅の三方両錐（90/120/180°）、SF₆の正八面体（90/180°）を拘束と誤差測定の両方に実装。
- SO₂/SO₃/硫酸の同等な末端S=Oは、1本棒＋淡い曲線の共有範囲記号で表示。S–OHは対象外。共鳴構造のランダム切替・電子の周回軌道は描かない。図鑑の3D/軽量表示/一覧サムネイルも同じ表現。曲線は定性的な教材記号であり、計算した電子密度ではない。
- 補正は表示中の経過時間2.4秒を上限とし、1.3秒以降は0.7秒間改善がない場合も終了。終了は「安定」と同義ではなく、未収束は「配置未解決」。非有限座標は最後の有限座標へ戻す。過密な環探索にも計算量上限を設け、上限到達時はグラフを保持して補正を止める。
- 背景に触れるか「補正を止める」で補正を中断して操作へ戻れる。未登録グラフも同じ扱い。局所ドラッグは移動幅を制限し、補正に失敗したときだけ操作部分を0.22秒で元の位置へ戻す。カメラ・非操作骨格は動かさない。
- 結合の登録有無、教材ルール上の充足、配置の収束を分離。明確な接続違反は成立前に拒否し、接続演出中も確定直前に再検証して直前の変更だけ取り消す。配置の未収束を理由に結合を切らない。任意分子の実在性・熱力学的安定性の判定は対象外。
- 全消去をフィールド上部に常設。1秒長押しで進捗表示、短いクリック/指外れ/中断/タブ非表示ではキャンセル。キーボードのSpace/Enter長押しにも対応。補正・接続・ドラッグを安全に中断して消去し、図鑑の記録は保持する。

`tests/bond-state.test.mjs`：全162分子を通常順/逆順で許可された接続から構築し認識。`tests/mobile-ui-check.mjs`：7分子を本番ドラッグ/接続演出/補正から完成させ、完成後の誤差も確認。`tests/special-bonds-check.mjs`：実Three.jsで高配位の全角度、平面、曲線の回転追従・資源解放。`tests/hold-action.test.mjs`：全消去の誤操作防止。既存の遠距離接続・リリース後画角保持も継続検証する。

## スマホ画面・図鑑・PWA（v29）

- スマホは100dvhとsafe-areaに対応した固定画面。上部ナビ、3Dフィールド、原子／部品トレー。長い説明・化学情報・全消去をメニューへ移し、全消去は確認付き。縦横の小画面とデスクトップに対応する。
- 分子図鑑は固定番号、模型の静的サムネイル、名前の一覧。詳細は操作可能な3D模型、短い紹介、前後移動。「くわしく」に英名・IUPAC・官能基・異性体・教材上の制約を残す。未発見の分子式はヒント操作後に表示。解放条件は従来どおり。
- `data/encyclopedia.json` は162分子／17部品の固定番号と短い紹介。追加時は既存番号を変更せず、新番号を割り当てる。化学構造DB・既存学習メモとは分離。
- `workspace-save.js` は `molecule-craft.workspace.v1` に原子・結合・座標・カメラ・選択・回転中心を保存する。直近の安定状態を復元し、自動緩和や表示合わせはしない。ドラッグ／緩和の途中で終了した場合は、その操作前の安定状態へ戻る。変更のないフレームでは書き込まない。
- 図鑑の既存保存は変更しない。破損セーブは全消去の明示操作まで保護し、未来版や別画面の更新との競合は上書きせず表示する。WebGLを起動できない環境では制作セーブを読み書きしない。クラウド同期ではない。
- PWAはGitHub Pagesのサブパス内に限定。アイコン、standalone表示、同一配信元のThree.js、全制作・図鑑資産のオフラインキャッシュ。**初回は通信が必要**。インストール操作はメニューに用意し、対応しない環境はブラウザの追加手順を案内。
- Service Workerは全資産のSHA-256を確認してから版を切り替える。公開途中の不一致・通信失敗時は旧版を保持。新しい版はメニューから保存後に更新し、操作中の自動リロードはしない。他のMolecule Craft画面が開いている場合、即時更新は保留する。
- 素材変更時は `node scripts/build-collection-assets.mjs`、配信ファイル変更時は **最後に** `node scripts/build-precache.mjs` を実行する。実行時のバンドルビルドは不要。旧版のアプリファイルはオフライン資産に含めない。
- `node tests/workspace-save.test.mjs`、`node tests/pwa.test.mjs` で保存保護と配信資産／SWを検証。`node tests/mobile-ui-check.mjs /path/to/jsdom/lib/api.js` は本番DOMと実Three.jsによる統合試験（WebGLのみ代替）。`tests/mobile-layout-harness.html` は縦横の実画面確認用。

## 現在の操作モデル

- 元素ボタンで未結合原子を追加
- 不対電子どうしを画面上でドラッグして、単結合・多重結合・環を形成
- 原子ごとに、不対電子があれば電子周辺の結合操作、なければ広い原子取得範囲を優先。原子中央は常に骨格操作。結合を壊すと対象原子だけ電子優先へ戻る
- 原子ドラッグで局所構造を調整し、単結合は軸回転可能
- 結合後はカメラを固定したまま、結合長・角度・sp/sp²・芳香族平面拘束へ段階的に緩和
- 既知化合物は `data/molecules.json` の構造グラフから認識し、慣用名を表示（IUPAC名は詳細）
- 完成・名前認識は連結構造ごとに独立。未結合原子が残っても各完成品を認識し、同じ分子を複数作った場合も別々に完成通知。構造一覧から表示対象を選択
- 「構造を表示」と背景ダブルタップは編集中の分子を表示。カメラ方向と原子座標を維持したまま約0.42秒で位置・ズームを調整。原子操作・構造緩和中の要求は予約しない
- 未完成の小片だけを距離で整理。主構造より小さく、8原子以下・非H原子2個以下で、主構造・完成品・大きな構造などから7モデル単位（C–C単結合約6本分）より離れた状態が4.5秒続くと、0.65秒でフェードして削除
- 近くの素材・完成品は削除しない。追加・選択解除後8秒は保護し、操作・緩和中や非表示タブでは整理を停止。「整理を元に戻す」で自動整理分を復元できる。整理は化学反応や原子消滅のシミュレーションではない
- 「完成」はこの教材モデルでの原子価充足を意味し、実際の化学的安定性を保証しない。DBにない構造も完成判定可能

## 原子解放・アルキル部品・図鑑拡張（v25）

追加位置（v28）：原子・構造部品は、まず現在の表示枠内の空きへ配置します。原子球・電子の外周と部品全体、既存の原子・結合、上部ボタン・下部案内を考慮します。枠内に収まらないときだけ探索範囲を外へ広げ、必要な距離まで約0.42秒でズームアウトします。視線方向・表示中心・既存原子は動かしません。部品の位置補正は配置前に独立グラフで計算し、配置後に二重に補正したり、補正終了後にカメラを動かしたりしません。表示上限まで広げても空きがない場合は、重ね置きせず追加を見送ります。

優先順位は、初期の選択肢を減らす原子解放 → 操作の反復を省く部品 → 部品を活用する収集対象の追加。化学上の重要度、操作短縮、既存部品との重複で選定した。

- 新規開始はH/C/O。異なる既知分子を3種類発見でN、6種類でCl、10種類でS、15種類でP/Fを解放。特定分子の制作や同じ分子の周回は要求しない。`element-progression.js`に条件を集約。初期元素だけで15種類以上を作れることをテストし、解放の循環依存を防ぐ。
- 未解放ボタンは隠し、次の元素と必要な新発見数だけ表示。8元素の静的HTMLは残す。JS起動失敗時にパレットが消えることはなく、DB/図鑑の読込失敗時は全原子を使える自由制作へ戻す。
- 図鑑の初期フィルタは「今の原子で作れる」。全件表示も可能で、未解放原子が必要な項目には条件を明記。解放通知は初発見通知に併記し、独立モーダルや通貨・経験値は増やさない。
- メチル基（–CH₃）を初発見で、イソプロピル基（–CH(CH₃)₂）とn-ブチル基（–CH₂CH₂CH₂CH₃）を異なる2種類の発見で解禁。エチル基は既存の`carbon-chain` idを維持し重複追加しない。計17部品、図鑑構造17種、内部24パターン。H数・結合次数・分岐をグラフで照合し、同じ式の別骨格を誤って解禁しない。
- 新しい3部品は接続点1個を持つ未完成の通常原子グラフとして展開。H自動補完・既存骨格への自動接続なし。メチル基＋カルボキシ基を手動接続して酢酸を発見するループもテスト。
- 分子DBは142→162件。クエン酸/コハク酸/リンゴ酸/マロン酸/アジピン酸/グリコール酸、クレゾール3種、サリチル酸メチル、酢酸イソアミル/酢酸n-ブチル/酢酸イソプロピル、安息香酸メチル/エチル、クメン、ベンジルアルコール、セリン/システイン/メチオニンを追加。発見後に短い学習メモを表示する。
- 追加20件はPubChem PUG RESTで分子式とConnectivitySMILESを確認。2026-08-30取得のCID・出典・接続式を`tests/fixtures/collection-expansion-reference.json`に固定し、生成器とは独立に組み立てたグラフで全件認識を検証する。アミノ酸・リンゴ酸は立体配置未指定として登録し、L/D別収集を装わない。糖類・カフェイン、形式電荷や新たな立体異性判定を要する項目は今回増やさない。
- 保存キーは従来の`molecule-craft.collection.v1`、schemaVersionは2。発見id/日時/順序/部品を引継ぐ。旧保存で発見済みの分子に含まれる元素は移行時に使用権を保持し、少数発見の既存ユーザーから取り上げない。無効idは発見数に加えず、将来schemaは上書きしない。v29から制作フィールドは別キーで保存する。

`tests/collection-expansion.test.mjs`は公開DBとの接続照合、全解放閾値、重複、旧保存の移行、部品の区別、実制作と同じグラフ接続、パレットの失敗時復帰を検証。`tests/collection-ui-harness.html`で本番保存を変更せずUIの解放・配置・発見・図鑑閲覧を試せる。原子を直接ドラッグする実機試験の代わりではない。

## リリース後の画角保持と分子フォーカス（v24）

- 再現できた原因：環のCをドラッグすると末端Hなどを支点に環のほぼ全体が回転し、リリース後は平面・角度拘束がその骨格を動かしていた。旧処理でアニソールの環Cを約132°動かす再現試験では、固定カメラの390×430px投影上でリリース後に約104px移動した。カメラ座標の変化ではない。
- `structure-edit.js` で操作領域と固定骨格を分離。重い骨格を末端Hや小さい置換基の周りに回さず、環原子は局所移動、外側の枝は枝単位で操作する。ドラッグ中に非操作骨格が指を追いかける全体緩和は行わない。
- リリース後は操作していない原子を拘束し、操作原子・枝だけを滑らかに補正。180msの立ち上がりと小さい補正強度を使い、低FPSでも初フレームで完成位置へ飛ばない。拘束を満たせない場合も固定骨格を解除して全体を動かすフォールバックは使わない。単結合torsionの意図した角度は保持する。
- ドラッグ確定後の追加タッチは操作を奪わず、未登録pointerのmove/up/cancelを無視する。表示合わせは明示操作の時だけ行い、緩和終了直後の予約実行を廃止。
- 複数構造がある場合、3D画面上の「編集対象」からフォーカスを切り替えられる。原子タップ・構造一覧でも切替可能。切替だけではカメラ・原子座標を変更しない。必要な場合に別途「構造を表示」を押す。
- 原子間反発も対象分子内だけで計算する。近くに別の完成品や原子が重なっていても、編集中の分子を押し出さず、別分子も動かさない。分子間の結合は従来どおり電子ドラッグで可能。

`node tests/release-motion-check.mjs /path/to/three/build/three.module.js`：15/60fps、メタン・エチレン・アセチレン・ベンゼン・アニソール・フェノールの22リリースケース、カメラ行列不変、非操作骨格の投影移動0px、画角保持、初フレームの飛び防止、別分子非干渉、カルボニル基のtorsion保持を検証する。同じチェックはブラウザハーネスにも搭載。局所的な拘束モデルのため、矛盾する配置をすべて解消できる保証はない。

## 遠距離接続と表示対象の回転（v23）

- 電子の結合判定は引き続きスクリーン上の距離のみ。電子対・結合線を表示した後、小さい方の断片を形ごと滑らかに寄せ、元素半径と結合次数から求めた結合長に合わせてから通常の緩和へ渡します。環閉鎖では断片移動を使わず、環全体の拘束を反復します。
- 結合長補正・角度補正は、切り分け可能な枝の内部構造を保ちます。終了判定は移動量や時間切れではなく、結合長誤差3.5%以下・角度誤差12°以下・平面誤差0.045以下が連続して満たされたかを確認します。フレーム当たりの計算予算を制限し、15fpsでも反復数不足で終了しません。
- 計算上限に達しても拘束を満たさない場合は「配置にひずみが残っています」と表示して操作を返します。教材用拘束モデルであり、すべての環・高配位分子のエネルギー最小配置を保証する物理シミュレーターではありません。
- 背景ドラッグ／2本指twistは、フォーカス中の分子だけを剛体回転します。表示合わせと回転で同じ中心を使い、背景タップによる原子選択解除でもフォーカスを維持。中心はジェスチャー中や回転を繰り返す間に再計算しません。構造変更後は更新します。
- 緩和は変更対象の連結成分に限定し、カメラ位置・注視点・zoomは変更しません。保存データや図鑑DBの形式は変えていません。

`node --test tests/*.test.mjs` で通常の全10スイートを実行できます。Three.js 0.180.0が利用できる場合、`node tests/structure-motion-check.mjs /path/to/three/build/three.module.js` で遠距離接続、枝の剛体移動、15/60fpsの単・二重・三重結合、ビニルアセチレン、環閉鎖、表示中心の保持を検証します。同じ検証は `tests/browser-harness.html` にも含まれます。

## 構造収集ゲームの基礎（v21時点。最新件数・解放条件はv25節）

原子から作る → 既知分子を初発見 → 図鑑に登録 → 共通する官能基・骨格を学ぶ → 部品解禁 → 部品を使って別の分子へ、という自由制作中心のループです。

- 分子図鑑は既存の教育向け142件を収集対象にしています。11カテゴリで進捗を表示し、未発見は名前を伏せて分子式とカテゴリを提示。追加ヒントで官能基・原子数を確認できます。
- 発見済みの詳細は日本語名・英語名・IUPAC名・別名・発見順/日付・回転できる立体模型・官能基を表示。同じ分子式の別構造も比較できます。模型は結合情報から生成した教材用配置で、発見時の姿勢や実測構造を保存したものではありません。
- 図鑑に表示する官能基/構造は、ビニル基・エチニル基・フェニル基など一般的な名称を持つ14種。内部では21パターンを使い、酸のOHとヒドロキシ基、エステルとメトキシ基、アミド結合とアミノ基、芳香環とフェニル基を構造グラフから区別します。
- クラフト部品14種は `data/craft-structures.json` に一般名称・別名・簡略構造式・原子・結合次数・接続点を明記。小さなヒドロキシ基/アミノ基/カルボニル基/ビニル基/エチニル基は初発見で解禁。ホルミル基/カルボキシ基/メトキシ基/エステル結合/カルバモイル基/シアノ基/チオール基/エチル基/フェニル基は、対応する構造を**異なる2種類の分子**で発見すると解禁。同じ分子を繰り返しても解禁は進みません。
- 発見済みの分子・構造詳細は、専用の閲覧用3D模型を表示。ドラッグ回転、ピンチ/ボタン拡大縮小、表示リセットができ、図鑑操作は制作フィールドの原子座標・カメラ・原子idを変更しません。WebGLを利用できない環境では同じ3D座標を軽量Canvas表示します。
- 模型は詳細を開いた時だけ生成。CPUの配置キャッシュは8件、閲覧済みサムネイルは24件まで。準備後は入力・リサイズ時だけ描画し、非表示時は停止、詳細切替/図鑑終了でイベント・mesh・material・GPU contextを解放します。部品の金色の接続点は原子や電子ではありません。
- 既存の発見分子idと日時は維持します。解禁状態は発見済み分子から新しい部品定義で再計算するため、従来の「任意の二重結合」を学んだだけではビニル基は解禁されません。
- 部品は通常の原子・結合へ展開して、選択原子の近く（未選択なら主構造の近く、空なら視点中心）に配置。最後の接続は通常の電子ドラッグで行います。Hの自動補完や未発見分子の自動生成は行いません。初期座標はトポロジーから生成する種配置であり、最終形は既存ソルバーが決めます。
- 初発見は約2.7秒の非モーダル通知。既発見は約1.2秒の小さな完成通知。同じ分子を複数作っても、メタ進行の初発見はstable idごとに1回です。
- `molecule-craft.collection.v1` にschemaVersion付きJSONをlocalStorage保存。発見分子id・日時/順序・構造の発見元・解禁部品・小さな構造マイルストーンのみを保存し、制作フィールドはv29の別キーに保存します。旧idや重複は無視、解禁状態は有効な発見元から再計算します。破損・保存拒否時は警告してメモリ内で継続。将来版の保存は上書きしません。
- 図鑑の探索/保存はトポロジー変更後、操作・緩和が落ち着いた時だけ。毎フレームのDB探索・官能基探索・保存はありません。図鑑の読み込み失敗時も基本クラフトは継続します。

主な責務：`collection-state.js`（進行/保存）、`functional-groups.js`（構造検出）、`craft-structures.js`（検証/通常グラフ展開/初期配置）、`collection-catalog.js`（カテゴリ/接続情報）、`collection-ui.js`（図鑑/パレット）。direct ES moduleは維持しています。

`preview-model.js`（独立グラフ/既存ソルバー）、`preview-controls.js`（閲覧用操作）、`collection-viewer.js`（WebGL/軽量3D描画）を制作画面から分離しています。

ベンゼン型の芳香族6員炭素環は、制作画面・図鑑ともに均一な1本棒6辺と水色の内円で表示します。内円はπ電子の非局在化を示す記号で、電子の軌道や追加の結合ではありません。`aromatic-rendering.js` が描画だけを変え、整数の結合次数・認識・原子価・配置計算は維持します。環を切断したり共役が失われたりすると通常の多重結合表示に戻ります。環外の二重結合と金色の接続点表示は維持します。

制約：SMARTS全対応ではなく、第一級アミノ基・ベンゼン型6員炭素環などに範囲を限定しています。cis/trans・鏡像異性体、クラウド同期、反応経路は未対応です。ゲーム進行はこのブラウザの保存領域に依存します。

## 起動

ビルドは不要です。HTTPサーバーから `index.html` を開いてください。GitHub Pagesでも動作します。

Three.js 0.180.0 は `vendor/three/` に同梱したMITライセンスのES Modulesを読み込みます。外部CDNへの接続は不要です。
